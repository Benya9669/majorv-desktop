# Major V Desktop

Панель управления Marshall Major V для Windows и Linux. Показывает заряд, управляет эквалайзером, M-кнопкой, подсказками и таймером. Основные настройки передаются по BLE, пять полос Individual EQ — через Bluetooth Classic. В приложении есть деморежим для проверки без Bluetooth.

## Установка

На [странице релизов](https://github.com/Benya9669/majorv-desktop/releases) выберите установщик `.exe` для Windows x64 или пакет `.deb` для Ubuntu 24.04+ amd64. Для локальной сборки эти файлы появляются в `dist/release/`. Установите пакет и запустите **Major V Desktop** из меню приложений. Установка новой версии поверх предыдущей сохраняет настройки и профили в каталоге или реестре пользователя. [Сборка и выпуск версии](docs/releases.md)

## Запуск из исходников

Понадобится Python 3.11 или новее. Выполняйте команды из корня репозитория. Первый запуск ниже открывает деморежим с виртуальными наушниками.

**Windows · PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m majorv --demo
```

**Linux**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m majorv --demo
```

В Linux нужен графический сеанс Qt (X11 или Wayland), а для физических наушников — работающий BlueZ и доступ к системной шине D-Bus. Если на Debian или Ubuntu недоступен модуль `venv`, установите пакет `python3-venv`. В минимальной системе ошибка импорта QtQml с упоминанием `libgssapi_krb5.so.2` означает, что нужен пакет `libgssapi-krb5-2`.

## От поиска до изменения настроек

1. Для работы с физическими Major V включите Bluetooth, выполните сопряжение в настройках ОС и запустите приложение без `--demo`. В Windows команда — `.\.venv\Scripts\python -m majorv`, в Linux — `.venv/bin/python -m majorv`.
2. Нажмите **Найти наушники**. В списке появятся имена и адреса найденных Major V. Выберите нужную пару и нажмите **Подключить**. Если система попросит подтвердить BLE-сопряжение, подтвердите его. Для чтения настроек требуется шифрованное соединение, даже если звук уже играет через Bluetooth Classic.
3. После подключения появятся заряд и текущие настройки. Прочерк у заряда или «Нет данных» у настройки означает, что получить значение не удалось.
4. Выберите пресет, действие M-кнопки или состояние подсказок. Приложение отправит изменение и перечитает значения. Оно принимает уведомления Bluetooth и дополнительно обновляет показания каждые 20 секунд.
5. При следующем запуске приложение само ищет последнюю подключённую пару. После обрыва оно очищает показания и повторяет подключение с увеличивающимся интервалом до 30 секунд. **Выбрать другие** останавливает попытки и открывает поиск. **Отключить** приостанавливает подключение до следующего запуска или ручного выбора.

В окне **Слоты EQ и таймер** видны оба пресета для переключения M-кнопкой. Можно выбрать активный слот, назначить пресет второму слоту и задать выключение через 15 или 20 минут без Bluetooth-соединения. Интервал при паузе воспроизведения сохраняется.

## Трей и уведомления

Крестик и кнопка сворачивания скрывают окно в системный трей. Приложение продолжает поддерживать связь с наушниками. Чтобы вернуть окно, щёлкните по значку Major V или выберите **Открыть Major V Desktop** в его меню. Там же можно посмотреть заряд, переключить EQ или полностью закрыть приложение через **Выйти**. Если системный трей недоступен, крестик завершает приложение.

В **Параметрах** можно выбрать порог низкого заряда 5, 10, 15 или 20% либо выключить уведомление. По умолчанию выбран порог 10%. Повторное подключение не дублирует предупреждение. Оно снова сработает после того, как приложение увидит заряд выше порога. Здесь же можно проверить наличие нового релиза и открыть страницу обновления.

В деморежиме выполните те же шаги. Кнопка **Имитировать потерю связи** позволяет проверить обрыв и повторное подключение. Виртуальные настройки хранятся до закрытия приложения.

## Консольный BLE-клиент и проверки

Примеры для активированного виртуального окружения. Можно также подставить путь к Python из команд запуска выше.

```shell
python scripts/majorv_client.py --help
python scripts/majorv_client.py --name "Major V" --pair status
python scripts/majorv_client.py --name "Major V" eq bass
python scripts/majorv_client.py --name "Major V" m-button eq
python scripts/majorv_client.py --name "Major V" prompts --off
python -m unittest discover -s tests -v
```

Для выбора конкретных наушников консольный клиент принимает `--address` вместо `--name`. В предыдущих аппаратных опытах воспроизведены команды `eq`, `m-button` и `prompts`. Экспериментальная команда `timer` учитывает только `--not-connected`, хотя CLI требует также `--connected-paused`.

## Individual EQ

Пункт **Individual** выбирает сохранённый пресет через BLE. Нажмите **Полосы Individual EQ**, чтобы прочитать пять усилений по Bluetooth Classic. При нескольких подходящих парах можно выбрать нужную из списка. Команда `python scripts/individual_eq.py read` также поддерживает автоматический поиск.

Для записи на наушники выберите пресет **Individual** на главном экране. Откройте **Полосы Individual EQ**, выставьте усиление на пяти частотах от 160 до 6250 Гц и нажмите **Применить**. У каждого ползунка диапазон ±6 дБ с шагом 0,12 дБ. После записи приложение перечитывает профиль из наушников. Если связь прервалась, снова откройте редактор и проверьте сохранённые значения. В деморежиме тот же сценарий работает без Bluetooth.

Для хранения кривой на компьютере укажите имя и нажмите **Сохранить**. **Отменить** возвращает предыдущую кривую в редактор. Чтобы вернуть её на устройство, нажмите **Применить** ещё раз.

Новый захват подтвердил все 248 блоков DSP, в том числе для 48 разных смешанных кривых. Старый захват подтвердил ещё 34 блока. [Команды чтения, записи и проверки по захвату](docs/individual-eq.md)
